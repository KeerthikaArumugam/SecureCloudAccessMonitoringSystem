Brier Score
Calibration quality (0=perfect, lower=better)
Why Recall Matters More Than Accuracy for Threat Detection

In security applications, missing a real threat (False Negative) is far more costly than a false alarm. A model with 99% accuracy but 0% recall would flag nothing and miss every attack. Recall measures how many actual suspicious logins were correctly identified — this is the primary metric for any intrusion detection system. The Brier Score measures probability calibration quality, ensuring stated confidence values correspond to actual empirical frequencies.

Class Imbalance Handling

Trained with class_weight="balanced". This prevents the model from being biased toward the majority (normal) class.

Stratified Split

Used stratify=y during train/test split to ensure proportional class distribution in both sets.

Dataset Scale

Trained on {{ '{:,}'.format(perf.train_samples) }} samples from the CERT Insider Threat dataset (logon events). Label distribution: ~4.3% suspicious, ~95.7% normal.

Threshold-Based Risk

Risk level derived from model probability: 0–30 → LOW, 31–70 → MEDIUM, 71–100 → HIGH. Thresholds are configurable.
